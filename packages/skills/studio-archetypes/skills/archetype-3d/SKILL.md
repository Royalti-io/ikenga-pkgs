# 3D Motion Graphics Archetype

This archetype provides procedural 3D text titles, beat-synced geometry visualizer meshes, and multi-view 3D character plates for Blender headless rendering and fal.ai conditioning.

## Supported Renderers
- `blender`: Headless Blender 3D rendering (`.blend` content)
- `fal`: AI image/video generation with multi-angle control plates

## Included Blocks
1. `3d.kinetic-type` — Kinetic 3D text animation
2. `3d.audio-visualizer` — Audio-reactive 3D mesh visualizer
3. `3d.anchor-plate` — Consistent multi-angle character anchor plates
